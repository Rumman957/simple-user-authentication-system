# CreateME

## What is it?
CreateME is a simulation of user authentication system that lets user create an account and then log into it after coming again or a page refresh.

## How to use it?
It's very easy to use. It is like that how you create an account and log in to it in real-world apps on daily basis.<br>
(If using for the first time)
1. Create an account by entering all the credentials such as name,email and password.
2. After that, click `Create Account` button and voila! your account is get created.<br>

(If you already have created your account and come later)
1. Enter the email and password to login.
2. Click `Login` button and you are into it!

There's an option to delete your account. Click the red button on the top-right corner of the page and your account will be deleted and create a new one if you'd like.😊

## Tech Stack:
- HTML5
- CSS3
- JS ES6+

## How does it store data?
CreateME uses browser's local storage to save user's data. As I have not reached a high level yet to use backend or database to store data that's why I used what I was capabale of using.

## Inspiration:
We all create accounts and logs into them on the daily basis. It's a very common task and I also do it on a high rate. This sparked curiousity in my mind that how does this all work which I do so commonly. That's why I decided to build this project and get an experience of behind-the-scenes (according to my current level).
